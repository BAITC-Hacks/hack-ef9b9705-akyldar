# Сценарий демо

Сценарий рассчитан примерно на пять минут и работает без внешнего AI-ключа.

## Подготовка

1. Запустите backend с `AI_FORCE_FALLBACK=true` и `SEED_DEMO_DATA=true`.
2. Запустите frontend с `VITE_API_URL=http://localhost:8080`.
3. В интерфейсе выберите режим «Бизнес».

## Сценарий

1. Нажмите «Создать задачу» и введите: `Хотим автоматизировать работу склада`.
2. Нажмите «Проанализировать задачу». Появятся минимум три уточняющих вопроса и подпись резервного режима ИИ.
3. Ответьте, например:
   - решением будут пользоваться кладовщики и руководитель склада;
   - доступны таблица Excel с остатками и история продаж;
   - нужен веб-интерфейс для контроля остатков и уведомлений о дефиците.
4. Нажмите «Создать карточку задачи». В резервном режиме исходное описание попадёт в поле «Контекст», а остальные сведения останутся для ручного заполнения.
5. Нажмите «Сохранить изменения». Backend рассчитает первый рейтинг; для одного заполненного поля ожидается `10/100` и уровень `Черновик`.
6. Заполните карточку: потребность, пользователей, данные и материалы, ограничения, ожидаемый результат, критерии успеха, контакт и формат взаимодействия. Сохраните изменения снова. При заполненных категориях ожидается `100/100` и уровень `Приоритетная`.
7. Нажмите «Подтвердить», затем «Опубликовать задачу».
8. Переключитесь в режим «Студент», откройте опубликованную задачу и отправьте предложение. Для seed-данных используйте идентификатор команды `1`.
9. Переключитесь обратно в режим «Бизнес», откройте предложения и вручную примите или отклоните предложение.

Рейтинг рассчитывается backend по реальным полям задачи; frontend не подставляет значения рейтинга в live-режиме.
