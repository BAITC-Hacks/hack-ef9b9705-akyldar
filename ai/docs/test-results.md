# Результаты проверки AI-стенда

Исходная проверка выполнена 23 сентября 2026 года в Windows PowerShell в изолированной рабочей папке без backend/frontend. Все файлы AI находятся в `ai/`. Ниже сохранена история этой проверки и отдельный результат переноса в командный репозиторий; live smoke исходного стенда не считается новым live-тестом клона.

## Проверка копии перед публикацией

23.09.2026 в отдельный клон командного репозитория перенесены 36 распространяемых файлов `ai/`; `.env`, `.local/`, portable tools и диагностические результаты не копировались. Ветка AI создана от `main` (`051f110`). Проверен код отдельной `origin/backend` (`ba61fef`), но backend не объединён с AI и его исходники не менялись.

Из `ai/` нового клона выполнены `go test -count=1 -cover ./...` (exit 0; пакет AI 94,4%, `cmd/demo` 0,0%), `go vet ./...` (exit 0), `go build ./...` (exit 0). `gofmt -l` для всех Go-файлов не вывел файлов. Использован Go 1.27.1 из исходного игнорируемого локального toolchain; `GOWORK=off`, `GOPROXY=off`, `GOSUMDB=off`, `GOTOOLCHAIN=local`. Для команды нужен установленный Go; исходный portable toolchain в Git не включён.

Это повторная offline-проверка копии. Новых live-вызовов и совместного end-to-end с backend/frontend при публикации не выполнялось. Успешные два live-запроса ниже относятся к предыдущей проверке исходного стенда.

## Среда

- Go `1.27.1 windows/amd64`, официальный переносимый архив `go1.27.1.windows-amd64.zip` с `go.dev`.
- SHA-256 архива проверен до распаковки: `a3911b5e0e1b1053f25ed0675f4c1c6aad1e2bfcf253df2b9be4caabd2edd95d`.
- Инструменты находятся в `.local/tools/go`, cache — в `.local/gocache` и `.local/gomodcache`; `.local/` исключён из Git через `ai/.gitignore`.
- Для проверки установлены `GOTOOLCHAIN=local`, `GOPROXY=off`, `GOSUMDB=off`. В модуле нет внешних зависимостей. Тесты не использовали API key или интернет; HTTP-тесты обращались только к локальным `httptest` servers.
- Первые попытки агентов запустить целевые тесты во время распаковки не дошли до компиляции: отсутствовала часть стандартной библиотеки. Итоговый полный запуск выполнен после завершения распаковки.

## Выполненные команды

Команды выполнялись из `ai/` с переносимыми `go.exe` и `gofmt.exe`. Ниже короткая запись тех же команд при добавлении `.local/tools/go/bin` в PATH текущего процесса:

| Проверка | Фактический результат |
|---|---|
| `gofmt -w` для всех Go-файлов модуля и `cmd/demo` | Exit 0 |
| `go test -count=1 -cover ./...` | Exit 0; `hackalem/ai`: PASS, 94,4% statements; `cmd/demo`: 0,0% unit coverage |
| `go vet ./...` | Exit 0; замечаний нет |
| `go build -o .local/demo.exe ./cmd/demo` | Exit 0; исполняемый стенд собран |

Автоматические тесты покрывают строгий JSON, обязательные/лишние/повторные ключи, неверные типы и `null`, 3–5 вопросов и нормализацию повторов, лимиты входа/выхода, полный card contract, code fences и посторонний текст, фактические anchors, конфигурацию, RU/KK fallback, отмену и deadline, missing key/model, forced fallback, Responses request format, отказ/обрезку ответа, закрытие body, запрет redirect, 401/403 без повтора и 429/5xx с максимум двумя обращениями. Отдельно проверяются synthetic envelopes, связи IDs, источники полных карточек и структура evaluation cases.

Это проверки программного поведения с заданными ответами. Они не доказывают качество настоящей модели или устойчивость prompt к любым инструкциям внутри данных. Race detector отдельно не запускался.

## Отдельные непроверенные части

**Live API smoke: passed, 23.09.2026.** После предоставления ключа создан локальный `.env` (исключён из Git); `OPENAI_MODEL=gpt-4.1-mini`, `AI_FORCE_FALLBACK=false`. Ключ не включён в этот отчёт, исходники или логи. Проверка выполнялась через реальные provider/service/handlers; HTTP request/response recorder заменял только локальный транспорт до handler, обращения provider к OpenAI были настоящими.

| Live-запрос | Результат |
|---|---|
| RU questions: `Хотим автоматизировать работу склада` | HTTP 200, `X-AI-Mode: live`, одна попытка, 5 вопросов, схема валидна |
| KK card: описание автоматизации бумажного учёта склада; ответы указывают кладовщика и веб-приложение для приёмки/выдачи | HTTP 200/live, одна попытка, схема валидна; неизвестные constraints/success_criteria/contact/interaction_format пусты |

Первая попытка из сетевого sandbox не достигла API (`provider_unavailable`, внешний HTTP status отсутствовал); после разрешённого сетевого запуска оба запроса выше прошли. Это не ошибка авторизации и не успешный live-ответ в исходной ограниченной среде.

Локальный Windows launcher `run.ps1` отдельно прошёл syntax check и 94 изолированные проверки на синтетическом `.env`: приоритет файла, quotes/comments, `-ForceFallback`, аргументы адреса, восстановление process env/CWD при exit 0 и 7, передача exit code, безопасные ошибки и отсутствие `.env`. Реальный секрет в этих проверках не читался. Проверены отсутствие API key в распространяемых исходниках и правило `.gitignore` для `.env`. Go-код при подключении ключа не изменялся.

**Полная семантическая оценка: not tested.** Два smoke-запроса доказывают подключение и базовую форму ответов, а не качество на всех сценариях. [18 semantic cases](../testdata/evaluation_cases.json) остаются для отдельной ручной live-оценки. Фиксировать `X-AI-Mode`, модель, ввод, результат и нарушения смысловых инвариантов; fallback не считать успешным live-вызовом.

**Полный platform end-to-end: not tested.** Исходный стенд был изолирован. В отдельной `origin/backend` (`ba61fef`) при передаче найдены модели, storage, rating и task/proposal routes, однако они не объединены с AI и не проверены в общем пользовательском flow. Полная разбивка по 15 шагам — в [integration-checklist.md](integration-checklist.md).

Контракт использует 11 явно перечисленных полей. Фраза задания о «12 полях» отмечена как несоответствие; произвольное двенадцатое поле не добавлено. Эти 11 полей совпадают с карточной частью просмотренной backend Task. Найденная формула rating, локальная зависимость между Go modules, CORS, timeout и двухэтапное сохранение описаны в [integration.md](integration.md) как предложение следующей интеграции.
